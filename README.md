# 💫 About Me:
I'm a software engineer who spends his days making things faster <br>APIs, queries, dashboards. The work is mostly unglamorous: <br>better PostgreSQL indexes, Redis in the right places, and async <br>handling where it was missing. SLA compliance went from 86% to 98%. <br>Nobody throws a party for that, but it matters. <br><br>Outside of that I build things I actually want to understand. A <br>cryptocurrency matching engine using the LMAX Disruptor pattern <br>1.69M ops/sec, single-threaded, zero GC pauses in steady state. <br>A recommendation system that fuses GraphSAGE collaborative filtering <br>with LLM text embeddings and CLIP vision features, hitting sub-100ms <br>latency in production. And SteerOps, a tool that steers transformer <br>model behavior at the activation level using PCA and forward hooks <br>no retraining, just surgery. I also shipped a patch to LibreOffice that got merged. <br>Millions of people have a menu item I wrote. Yeah, hurray!! <br>Completed B.Tech. ICT with a minor in computational science from DA-IICT.
